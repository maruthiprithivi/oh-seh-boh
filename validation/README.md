# Separately reviewed Linux validation packet

These sources are unexecuted. They observe the exact published OSB/PStack inputs in plan.example.json; they do not change either implementation, allocate a machine, install dependencies, add keys, use LLMs or authorize a pilot. Keep this packet separate from the pinned target checkouts, and verify its published commit/archive before execution.

1. The supervisor supplies an existing authorized Linux route, enforces 1–2 admitted CPUs plus memory/I/O constraints, verifies spare capacity and monitors shared workload impact within the existing spend/time cap. The consolidated job requires an existing exclusive cgroup-v2 test containment, initially containing only the job, inherited by all its children. The supervisor controls membership and must not place shared workloads there. The job reads it and uses pidfds to settle only its contained descendants, including new process sessions; it never creates a cgroup or moves processes. Missing containment or pidfd support refuses the job and needs a separately approved admission mechanism, not an automatic access change.
2. Supply three exact clean checkouts, preprovisioned Bun/commander with valid bootstrap install key, and the independently reviewed authority-owner validator with the documented `bash JOB SOURCE EVIDENCE` interface and SHA256. No unresolved example placeholder is executable.
3. Copy the example into a private plan, fill exact owner pin/hash, absolute paths and admitted CPU IDs, then set authorized_disposable_linux true only after admission. Preset workload/thresholds before seeing results. An editable flag is not an access approval.
4. Invoke `python3 /approved/reviewed-validation/run.py --plan /private/admitted-plan.json` through the supervisor's existing affinity route. The job refuses a mismatched affinity, missing dependencies or stale pin; no automatic provisioning follows.
5. Preserve report.json, each stage's stdout/stderr/exit/wall time, actual-store observations/DB snapshots, mutations and profile snapshots. A timeout, cancellation, unmet gate or absent evidence is failure/incomplete, never pass. Private synthetic journals and absolute paths should not be posted publicly.

Run the already frozen 15-fixture plus installed-PStack packet first when a route becomes available. This consolidated job adds owner suites/reference profiles/independent oracle checks and must fit the actual remaining budget; do not delay first evidence to build more features. Its entire one-hour bound includes setup with a 30-second cleanup reserve. Initial/final pin subprocesses share the remaining deadline; they cannot each start a fresh ten-second budget beyond it. The owner validator's own suite bounds can consume most of that hour. Stop or classify incomplete rather than extending the approved allocation silently. The parent remains responsible for an external wall/spend watchdog and emergency containment settlement if the job itself is killed or storage/kernel operations become unresponsive.

The admitted containment must be a supervisor-owned **leaf**, nondelegated to the test user: no child cgroups and no write access to its directory/membership file. The job checks those prerequisites and refuses a child cgroup rather than treating direct members as the entire tree. A privileged/root job cannot satisfy the nondelegated guard; the supervisor must supply an already authorized unprivileged route or stop for a separately approved admission change. Unexpected child-group creation/escape requires external supervisor reconciliation. Containment settlement still runs if process-group signaling races with group disappearance.

`oracle.py` imports no tested backend/client/overlap code. `reference_profile.py` wraps the pinned load harness only to capture raw post-run observations before its temporary DB disappears; it does not change transition semantics. Actual PStack mutation controls operate only on disposable runner copies and require specific forbidden observations. Missing/malformed observations refuse. A passing reference profile does not certify an actual authority's capacity or a real harness.
